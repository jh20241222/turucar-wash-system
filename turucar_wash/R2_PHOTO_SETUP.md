# 세차 현장 사진 저장소 (Cloudflare R2) 설정 가이드

차량소속 **'피플카 카셰어링'**, **'휴맥스모빌리티'** 차량은 세차 오더 상세 화면(`/car_detail/<id>`)에서
사진을 슬롯별로 바로 촬영/업로드하고 관리할 수 있습니다 (`카일이삼제스퍼`는 추후 추가 예정이라 현재는 제외됨 —
`app.py`의 `PHOTO_UPLOAD_ORGS`에 추가하면 언제든 켤 수 있습니다). 사진 원본은 Railway가 아니라
Cloudflare R2(용량 걱정 없는 외부 저장소)에 저장되고, 앱 DB(`wash_photos` 테이블)에는 파일 위치(키)만 남습니다.

이 기능이 실제로 동작하려면 **Cloudflare R2 계정/버킷을 한 번만 만들고, API 토큰을
Railway 환경변수에 등록**해야 합니다. 아래 순서대로 하면 됩니다.

## 1. Cloudflare 계정 만들기

1. https://dash.cloudflare.com/sign-up 에서 회사 이메일로 가입합니다 (이미 계정이 있으면 로그인).
2. 왼쪽 메뉴에서 **R2 Object Storage**를 클릭합니다. 결제 정보(카드) 등록을 요구할 수 있는데,
   R2는 매달 10GB까지 무료이고 그 이후로도 매우 저렴합니다(본문 하단 비용 참고).

## 2. 버킷 만들기

1. R2 화면에서 **Create bucket** 클릭
2. 버킷 이름: `turu-wash-photos` (다른 이름을 쓰면 아래 3단계 `R2_BUCKET_NAME` 값도 그 이름으로 바꾸면 됩니다)
3. Location: Automatic 그대로 두고 생성
4. **버킷을 Public으로 켜지 마세요** — 앱이 서명된 임시 URL로만 사진을 보여주도록 만들어져 있어서,
   버킷은 비공개(Private) 상태여야 안전합니다. 기본값이 비공개이니 별도로 손댈 필요는 없습니다.

## 3. API 토큰 발급

1. R2 화면 오른쪽 위 **Manage R2 API Tokens** (또는 계정 > R2 > API 토큰) 이동
2. **Create API Token** 클릭
3. 권한: **Object Read & Write**
4. 가능하면 위에서 만든 `turu-wash-photos` 버킷 하나로만 범위를 제한합니다 (권한 최소화)
5. 생성하면 아래 3가지 값이 나옵니다. 이 화면을 벗어나면 Secret은 다시 볼 수 없으니 바로 복사해두세요.
   - **Access Key ID**
   - **Secret Access Key**
   - **Account ID** (또는 토큰 발급 화면/R2 개요 화면 우측에 항상 표시됨)

## 4. Railway에 환경변수 등록

Railway 프로젝트 → 이 서비스 → **Variables** 탭에서 아래 4개를 추가합니다.

```text
R2_ACCOUNT_ID=<3단계에서 복사한 Account ID>
R2_ACCESS_KEY_ID=<3단계에서 복사한 Access Key ID>
R2_SECRET_ACCESS_KEY=<3단계에서 복사한 Secret Access Key>
R2_BUCKET_NAME=turu-wash-photos
```

저장하면 Railway가 자동으로 재배포합니다. `requirements.txt`에 `boto3`를 이미 추가해뒀으니
별도 설치 작업은 필요 없습니다.

## 5. 동작 확인

1. 마스터 계정으로 로그인
2. 세차 대상 목록에서 차량소속이 '피플카 카셰어링' 또는 '휴맥스모빌리티'인 차량 카드를 클릭
3. 차량 상세 화면 하단(모바일) 또는 하단 카드(데스크탑)에 **"세차 사진"** 슬롯 그리드(외부10+내부4+특이사항3+무인훼손제보)가 보이는지 확인
   - 환경변수가 아직 없으면 "사진 저장소가 아직 설정되지 않았습니다" 안내와 함께 "내역업로드" 버튼이 비활성화됩니다 — 정상입니다.
4. 환경변수 등록 후에는 슬롯을 눌러 촬영/업로드하고, 썸네일이 뜨는지, 눌렀을 때 원본이 열리는지 확인
5. 마스터 계정으로 "세차 내역 조회" 화면에서 사진의 X 버튼을 눌러 삭제가 되는지도 확인 (삭제는 마스터만 가능)

## 6. 무인훼손 제보 슬롯 + 슬랙 알림도 같이 쓰려면

"무인훼손 제보" 슬롯에 사진을 올리고 "내역업로드"를 누르면, 기존 훼손 제보 기능과 완전히 동일한
경로로 `damage_reports`에 기록되고 슬랙 전송을 시도합니다. 슬랙 전송이 실제로 되게 하려면 아래 중
하나를 Railway Variables에 추가로 등록하세요 (둘 다 없으면 콘솔에 로그만 남기고 조용히 넘어갑니다 — 에러는 아닙니다).

```text
# 권장 (사진을 슬랙에 영구 첨부, Railway 디스크가 지워져도 안전)
SLACK_BOT_TOKEN=xoxb-...
SLACK_CHANNEL_ID=C0XXXXXXX

# 또는 더 간단한 대안 (사진은 앱 서버가 호스팅하는 임시 URL로 링크됨)
SLACK_DAMAGE_WEBHOOK=https://hooks.slack.com/services/...
```

## 7. 촬영 사진 워터마크에 한글 주소 찍으려면 (카카오 로컬 API)

촬영 화면에서 사진을 찍으면 우측 하단에 날짜/시간과 함께 촬영 위치가 찍히는데, 좌표
대신 "2-42 대조동 / 은평구 / 서울특별시"처럼 한글 주소로 보여주려면 카카오 로컬 API 키가
필요합니다. 키가 없으면 에러 없이 그냥 좌표(위도, 경도)로 대체되어 찍힙니다.

1. https://developers.kakao.com 에서 로그인 후 "내 애플리케이션" → "애플리케이션 추가하기"
2. 만든 앱 → 왼쪽 메뉴 "앱 키"에서 **REST API 키** 복사 (JavaScript 키 아님, REST API 키입니다)
3. 왼쪽 메뉴 "카카오 로그인" 등은 건드릴 필요 없고, 기본 상태로 바로 좌표→주소 변환(로컬 API)이 됩니다
4. Railway Variables에 아래 1개 추가:

```text
KAKAO_REST_API_KEY=발급받은 REST API 키
```

무료 사용량(일 30만 건)으로 충분합니다. 카카오 REST API 키는 브라우저에 노출되지 않고
서버(`/api/reverse_geocode`)를 통해서만 호출되므로 안전합니다.

## 참고: 예상 비용 (무기한 보관 기준)

월 4,000건 × 20장 = 월 80,000장, 장당 압축 후 평균 ~200KB 가정 시 월 약 16GB씩 누적됩니다.

| 누적 기간 | 누적 용량 | R2 월 저장비용(추정) |
|---|---|---|
| 1년 | ~190GB | 약 $2.85 |
| 3년 | ~570GB | 약 $8.6 |
| 5년 | ~950GB | 약 $14 |

R2는 사진을 조회(다운로드)할 때 나가는 트래픽 비용(egress)이 없어서, 위 저장비용이 사실상
전체 비용입니다. 실제 청구 금액은 Cloudflare 대시보드 R2 사용량 화면에서 확인할 수 있습니다.

## 나중에 다른 차량소속도 사진 업로드 대상에 추가하고 싶다면

`app.py`에서 `PHOTO_UPLOAD_ORGS = {"피플카 카셰어링", "휴맥스모빌리티"}` 부분을 찾아 소속명을 더 추가하면 됩니다.
예: `카일이삼제스퍼`를 다시 켜고 싶으면 → `PHOTO_UPLOAD_ORGS = {"피플카 카셰어링", "휴맥스모빌리티", "카일이삼제스퍼"}`
